# Learning

A personal repository for notes, experiments, and practice projects while I learn new things.

## What's in here

This repo is just getting started. As it grows, I'll organize it by topic, for example:

- `notes/` for written notes and summaries
- `exercises/` for practice problems and small programs
- `projects/` for larger things I build along the way

## Getting started

Clone the repository:

```bash
git clone https://github.com/zaidxyd/learning.git
cd learning
```

Each folder will include its own instructions where needed.

## Goals

- Build skills through hands-on practice
- Keep a record of what I've learned
- Revisit and improve old work over time

## Contributing

This is a personal learning space, but suggestions and corrections are welcome. Feel free to open an issue.
